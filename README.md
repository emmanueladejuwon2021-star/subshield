# SubShield

Team software subscription and seat cost tracker.

## Live site (GitHub Pages)

After you turn Pages on, the app is at:

https://emmanueladejuwon2021-star.github.io/subshield/

Turn it on once:

1. Open https://github.com/emmanueladejuwon2021-star/subshield/settings/pages
2. Under **Source**, choose **Deploy from a branch**
3. Branch: `gh-pages` / folder: `/ (root)`
4. Save

The app stores data in the browser on GitHub Pages, so every tab works without a separate server.

## Local run

```
npm install
cd client && npm install && cd ..
npm run dev
```
